# Форма — Telegram-бот и мини-приложение для тренировок

Бот задаёт вопросы при старте (пол, возраст, рост, вес, цель, где занимаешься, опыт, сколько дней, ограничения) и открывает мини-приложение с планом, собранным по ответам. Без ИИ: план строится по правилам из базы упражнений.

## Что умеет

**Бот** (`bot/bot.py`, Python 3.8+, без зависимостей)

- `/start` — анкета кнопками и числами, затем кнопка «Открыть приложение».
- `/profile` — посмотреть анкету и изменить любое поле; `/app`, `/reset`, `/help`.
- Кнопка меню рядом с полем ввода тоже открывает приложение.

**Мини-приложение** (`index.html`, один файл, без сборки)

- **Сегодня** — тренировка дня, привычки (белок, калории, сон, вода, шаги), уровень и XP.
- **Тренировка** — подходы с весом и повторами, таймер отдыха, подсказки техники, замена упражнения, если тренажёр занят. Сделал верх диапазона во всех подходах — в следующий раз вес повышается сам.
- **Прогресс** — график веса тела, сила по упражнениям (расчётный максимум), рекорды, замеры, карта тренировок, достижения.
- **План** — почему план такой, неделя, все тренировки, питание, техника упражнений.
- Настройки (кнопка в шапке) — анкета, дни тренировок, резервная копия.

План зависит от анкеты: 2–6 дней в неделю, зал или дом (с учётом инвентаря), три уровня опыта, четыре цели, ограничения по пояснице, плечам, коленям, шее и осанке.

Прогресс хранится в облаке Telegram (CloudStorage) и синхронизируется между устройствами. Вне Telegram приложение тоже работает — данные лежат в браузере.

## Запуск

1. **Мини-приложение.** Включи GitHub Pages: Settings → Pages → Deploy from a branch → ветка с этим кодом, папка `/`. Адрес будет `https://<логин>.github.io/Training/`. Подойдёт и любой другой https-хостинг статики.
2. **Бот.** Создай бота у [@BotFather](https://t.me/BotFather) (`/newbot`) и скопируй токен.
3. Скопируй `bot/.env.example` в `bot/.env`, впиши `BOT_TOKEN` и `WEBAPP_URL`.
4. Запусти:

```bash
python3 bot/bot.py
```

Бот работает через long polling: ему не нужен домен или открытый порт, достаточно любой машины с интернетом (VPS, домашний компьютер). Анкеты лежат в `bot/data/users.json`.

## Как это связано

Бот кодирует анкету в ссылку кнопки (`?p=...`), приложение читает её при открытии. Если анкету изменили и в боте, и в приложении, побеждает более свежая. Сервер для приложения не нужен.
