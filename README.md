# Квест: форма к лету

Трекер домашних тренировок в виде пиксельной RPG. Один файл `index.html`, без сборки и зависимостей.

## Что умеет

- **Герой** — уровень, XP, характеристики, серия дней подряд, счётчик дней до лета.
- **Квест дня** — тренировка на сегодня: подходы, повторы, таймер отдыха, подсказки по усложнению.
- **Побочные квесты** — белок, калории, сон, перерывы от сидения, вода.
- **Прогресс** — график веса, карта тренировок за 12 недель, контрольные замеры, рекорды, достижения.
- **Книга** — техника упражнений, расписание недели, питание.

## Запуск

Открой `index.html` в браузере. Прогресс хранится в браузере (localStorage); в настройках есть резервная копия текстом.

Чтобы открыть с телефона, включи GitHub Pages: Settings → Pages → ветка `main`, папка `/`.

## План

Условия: дом, 30 минут каждый день, 2 гантели по 12 кг, гиря 16 кг. Цели: мышечная масса, осанка, уменьшение гиперлордоза. Подробности — в [docs/plan.md](docs/plan.md).
